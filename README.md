# Hoarding (NeoForge 1.21.1)

[English](./README_EN.md) | 简体中文

Forge 1.20.1 版本的 NeoForge 1.21.1 移植版。

## 设计思路

存储方块的设计参考了 Farmer's Delight 和 Quark。

## 功能

- 102 种原版存储方块（农作物、花朵、蘑菇、战利品）
- 18 种模组整合方块（Botania 16 色 + Ars Nouveau 2 种）
- 9 个物品 = 1 个存储方块，破坏后返还

## 安装

1. 下载 [Releases](https://github.com/3453890470/Hoarding/releases) 中的 .jar
2. 扔进 `mods` 文件夹
3. 启动 NeoForge 1.21.1

## 模组整合

需要先安装对应模组：

- **Botania** - 16 色矮花箱子
- **Ars Nouveau** - 法师之花箱子、魔源浆果箱子
