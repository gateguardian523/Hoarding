# Hoarding (NeoForge 1.21.1)

English | [简体中文](./README.md)

A NeoForge 1.21.1 port of the Forge 1.20.1 version.

## Design

Storage blocks inspired by Farmer's Delight and Quark.

## Features

- 102 vanilla storage blocks (crops, flowers, mushrooms, loot)
- 18 mod integration blocks (Botania 16 colors + Ars Nouveau 2)
- 9 items = 1 storage block, break to return items

## Installation

1. Download .jar from [Releases](https://github.com/3453890470/Hoarding/releases)
2. Put it in `mods` folder
3. Launch NeoForge 1.21.1

## Mod Integration

Requires the corresponding mod installed:

- **Botania** - 16 color mystical flower crates
- **Ars Nouveau** - Magebloom crate, Sourceberry crate
